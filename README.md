# Calculator


A clean, responsive calculator featuring a modern neumorphic design using HTML, CSS, and JavaScript.

---

## Features

- Responsive and mobile-friendly layout  
- Neumorphic container with subtle gradient border  
- Dark-themed calculator interface for easy readability  
- Supports basic operations: addition, subtraction, multiplication, division, percentage  
- Clear and backspace functionality
